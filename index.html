User Guide

App Overview

Мої Докі is an offline-first application. This means it doesn't require an active internet connection to function, and all your data is stored strictly and securely on your own device. It automatically tracks the validity of your documents and notifies you when they are expiring, so you never miss a renewal deadline.

Getting Started

When you open the application for the first time, you can set up a secure PIN Code.

  • This PIN prevents unauthorized access to your archived documents.
  • Note: Please remember this PIN. Because your data is encrypted and stored locally on your device, there is no remote server that can recover a forgotten PIN.

User Interface Overview

The main interface is divided into several areas for quick access:

  • Top Bar: Contains the main Search input, quick action buttons (Dashboard, Calendar Export, Print Report, Settings), and the "+ Add Document" button.
  • Sidebar / Filter Panel: Allows you to quickly filter documents by status (Active, Archive, Expiring, Valid, etc.), Tags, or change the sorting order.
  • Main Document Area: Displays all your documents as tiles or lists.
  • Dashboard (Statistics): A visual overview of your document statuses (Total, Valid, Expiring Soon, Expired, Permanent) and a timeline of upcoming expirations.

Step-by-Step Guidance

Adding a Document

  1. Click the + Add Document button in the top right corner (or the floating button on mobile).
  2. Fill in the essential details:
    • Title: The name of the document (e.g., "Basic Safety Training").
    • Number: (Optional) Document ID or serial number.
    • Dates: Enter the "Issue Date" and "Expiry Date". If the document does not expire, check the "Permanent / No Expiry" checkbox.
    • Tags: Add categories (e.g., "Medical", "Seaman's Book") to make filtering easier.
  3. Upload Files: Click to browse or drag-and-drop a scan/photo of the document (PDF, JPG, PNG).
  4. Click Save. The document is now stored in your archive.

Viewing and Editing Documents

  1. Click on any document card to open the preview modal.
  2. In the preview, you can view the attached file.
  3. To edit the document's details, click the Edit (✏️ Pencil) icon in the top right corner of the preview.
  4. To download a copy of the original file, click the Download (⬇️) icon.

Searching and Filtering

  • Search: Use the search bar at the top to instantly find documents by name, number, or description.
  • Filter by Status: Use the left sidebar to show only "Active" or "Archive" documents, or filter by expiration status (e.g., "Expiring Soon").
  • Filter by Tags: Click on any tag in the sidebar to only show documents with that specific category.

Tools & Settings

The application provides several powerful tools to manage your archive:

  • Dashboard (📊 Chart Icon): View a summary of your documents and a 360-day timeline of upcoming expirations.
  • Print Report (🖨️ Printer Icon): Generates a clean, printable summary list of all your currently active documents.
  • Calendar Export (📅 Calendar Icon): Exports your document expiration dates as an .ics file. You can import this file into Google Calendar, Apple Calendar, or Outlook to get native phone reminders.
  • Backup & Restore (💾 Save Icon): Found in Settings. You should regularly click "Backup" to save a secure copy of your entire vault to a .json file on your computer. If you switch devices, you can "Restore" from this file.

Огляд застосунку

Мої Докі працює повністю офлайн. Це означає, що для його роботи не потрібне підключення до Інтернету, а всі ваші дані зберігаються суворо та надійно на вашому власному пристрої. Застосунок автоматично відстежує термін дії ваших документів та повідомляє, коли вони закінчуються, щоб ви ніколи не пропустили час поновлення.

Початок роботи

Відкриваючи застосунок вперше, ви можете налаштувати безпечний PIN-код.

  • Цей PIN-код запобігає несанкціонованому доступу до вашого архіву.
  • Примітка: Будь ласка, запам'ятайте цей PIN-код. Оскільки ваші дані зашифровані та зберігаються локально на вашому пристрої, віддаленого сервера, який міг би відновити забутий PIN, не існує.

Огляд інтерфейсу користувача

Головний інтерфейс поділено на кілька зон для швидкого доступу:

  • Верхня панель (Top Bar): Містить головне поле пошуку, кнопки швидких дій (Статистика, Експорт у календар, Друкований звіт, Налаштування) та кнопку "+ Додати документ".
  • Бічна панель / Фільтри: Дозволяє швидко фільтрувати документи за статусом (Активні, Архів, Спливають, Дійсні тощо), тегами, або змінювати порядок сортування.
  • Головна область документів: Відображає всі ваші документи у вигляді плиток або списку.
  • Статистика (Dashboard): Візуальний огляд статусів ваших документів (Всього, Дійсні, Спливають, Прострочені, Безстрокові) та шкала часу найближчих термінів закінчення.

Покрокова інструкція

Додавання документа

  1. Натисніть кнопку + Додати документ у правому верхньому куті (або плаваючу кнопку на мобільному пристрої).
  2. Заповніть основні дані:
    • Назва: Назва документа (напр., "Basic Safety Training").
    • Номер: (Необов'язково) ID документа або серійний номер.
    • Дати: Введіть "Дату видачі" та "Дійсний до". Якщо документ не має терміну дії, встановіть прапорець "Безстроковий документ".
    • Теги: Додайте категорії (напр., "Медичні", "Паспорт моряка"), щоб полегшити фільтрацію.
  3. Файли документа: Натисніть, щоб вибрати, або перетягніть сюди скан/фотографію документа (PDF, JPG, PNG).
  4. Натисніть Зберегти. Документ тепер зберігається у вашому архіві.

Перегляд та редагування документів

  1. Натисніть на картку будь-якого документа, щоб відкрити вікно попереднього перегляду.
  2. У вікні перегляду ви можете побачити прикріплений файл.
  3. Щоб відредагувати деталі документа, натисніть на іконку Редагування (✏️ Олівець) у верхньому правому куті вікна перегляду.
  4. Щоб завантажити копію оригінального файлу, натисніть на іконку Завантажити (⬇️).

Пошук та фільтрація

  • Пошук: Використовуйте рядок пошуку вгорі, щоб миттєво знайти документи за назвою, номером або примітками.
  • Фільтр за статусом: Використовуйте ліву бічну панель, щоб показати лише "Активні" або "Архівні" документи, або фільтруйте за статусом терміну дії (напр., "Спливають").
  • Фільтр за тегами: Натисніть на будь-який тег на бічній панелі, щоб показати лише документи з цією конкретною категорією.

Інструменти та налаштування

Застосунок надає кілька потужних інструментів для управління вашим архівом:

  • Статистика (📊 іконка Графіка): Перегляд короткого підсумку ваших документів та шкали часу майбутніх закінчень термінів дії на 360 днів.
  • Друкований звіт (🖨️ іконка Принтера): Створює чистий, зручний для друку підсумковий список усіх ваших активних документів.
  • Експорт у календар (📅 іконка Календаря): Експортує дати закінчення терміну дії ваших документів у файл .ics. Ви можете імпортувати цей файл до Google Календаря, Apple Календаря або Outlook, щоб отримувати нативні нагадування на телефон.
  • Резервна копія та Відновлення (💾 Налаштування): Знаходяться в Налаштуваннях. Рекомендується регулярно натискати "Зберегти копію", щоб надійно зберігати весь ваш архів у файл .json на вашому комп'ютері. Якщо ви зміните пристрій, ви зможете "Відновити" дані з цього файлу.
