# Мої Докі

Offline-first Progressive Web App (PWA), створений як безпечний архів та система управління вашими найважливішими сертифікатами, ліцензіями та посвідченнями. Додаток дозволяє оцифровувати важливі документи, відстежувати терміни їх дії та надійно блокувати доступ за допомогою PIN-коду.

## 🚀 Основні функції

*   **Повна автономність (PWA):** Створено з використанням Service Workers, що гарантує доступність ваших даних та додатку навіть без підключення до Інтернету. Всі дані зберігаються виключно на вашому локальному пристрої через IndexedDB.
*   **Моніторинг термінів дії та сповіщення:** Автоматично відстежує статус ваших документів (Дійсні, Спливають, Прострочені, Безстрокові). Рухомий рядок зі сповіщеннями привертає увагу до документів, термін дії яких закінчується або вже минув.
*   **Безпека та конфіденційність:** Реалізовано систему блокування за допомогою PIN-коду з можливістю налаштування автоблокування для захисту ваших приватних документів на спільних пристроях. *Включає сувору перевірку PIN-коду перед дозволом на зміну або видалення існуючих документів.*
*   **Двомовність:** Повна, динамічна локалізація українською та англійською мовами, включаючи форматування дат та логотипів бренду (МР / MR).
*   **Управління документами та організація:**
    *   Додавайте детальну інформацію до ваших документів: назви, ідентифікаційні номери, дати видачі, терміни дії, власні описи та інформацію про орган видачі.
    *   Завантажуйте та зберігайте зображення (мініатюри) ваших документів безпосередньо в архіві.
    *   Легко категоризуйте документи за допомогою кольорових тегів, які можна налаштувати.
    *   Архівуйте старі документи замість їх повного видалення.
*   **Пошук, фільтрація та сортування:** Потужний рядок пошуку та інструменти фільтрації для швидкого пошуку конкретних документів за їх статусом, тегами, або сортування за найближчим закінченням терміну дії чи назвою.
*   **Експорт даних та резервне копіювання:** 
    *   Безпечно створюйте резервну копію всього вашого архіву (документи, зображення та налаштування) у локальний файл JSON, та відновлюйте його в будь-який час.
    *   Експортуйте дати закінчення терміну дії безпосередньо у ваш календар (формат `.ics`), щоб ніколи не пропустити термін оновлення.
    *   Генеруйте зручні для друку звіти ваших активних документів.
*   **Динамічні теми:** Плавне перемикання між світлим та темним інтерфейсом.
*   **Адаптивний дизайн:** Спеціально розроблені CSS та Flexbox макети гарантують бездоганний досвід користування на надшироких моніторах, стандартних планшетах та надзвичайно вузьких екранах мобільних пристроїв (аж до 320px).

## 🛠️ Технологічний стек

*   **HTML5 та CSS3:** Семантична розмітка з сучасними адаптивними CSS-змінними та макетами grid/flexbox.
*   **Vanilla JavaScript (ES6+):** Чистий, легкий JavaScript для швидкого виконання та маніпуляцій з DOM без використання важких фреймворків.
*   **IndexedDB:** Для надійного та масштабованого локального зберігання структурованих даних та об'єктів (зображень).
*   **Service Workers:** Для кешування ресурсів, забезпечення роботи в автономному режимі та створення повноцінного PWA.

## 📦 Встановлення та використання

1.  **Десктопний додаток (Нове!):** Ви можете зібрати додаток як самостійний інсталятор Windows (`.exe`). Просто виконайте `npm install` та `npm run dist`, щоб створити власний настільний додаток за допомогою Electron!
2.  **Локальний запуск:** Ви можете запустити цей проект локально, використовуючи будь-який стандартний HTTP-сервер (наприклад, VS Code Live Server, `python -m http.server`, `npx serve` тощо). 
3.  **Встановлення як веб-додатку (PWA):** Відкрийте URL-адресу в підтримуваному браузері (Chrome, Edge, Safari) та виберіть «Встановити додаток» (Install App) або «Додати на головний екран» (Add to Home Screen), щоб встановити його як самостійний додаток.
4.  **Почніть додавати документи:** Встановіть свій надійний PIN-код під час першого запуску, натисніть «+ Додати документ» і почніть безпечно архівувати свої ліцензії та сертифікати!
